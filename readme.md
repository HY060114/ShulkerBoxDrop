# ShulkerBoxDrop 使用说明

## 使用说明

1. **安装插件**  
   下载最新版本的 `.jar` 文件，放入服务器 `plugins/` 目录。

2. **启动服务器**  
   重启或执行 `/reload` 加载插件。首次运行会自动生成配置文件。

3. **配置（可选）**  
   编辑 `plugins/ShulkerBoxDrop/config.yml` 文件：
   - `threshold`：触发复制所需的累计挖掘数量（默认 `10`）。
   - `enable-message`：是否在触发时发送提示（默认 `true`）。
   - `message`：自定义提示消息（支持颜色代码，如 `&a`）。

4. **在游戏中使用**  
   玩家正常挖掘潜影盒，累计达到 `threshold` 设定值时，系统会额外掉落一个与当前挖掘的潜影盒完全一致的复制品，并重置计数。

---

## 注意事项

- 复制品是玩家挖掘的**第 n 个**潜影盒的精确副本（包含内部物品、名称、附魔等所有 NBT 数据）。
- 每位玩家的挖掘计数**独立**，互不干扰。
- 服务器重启后计数数据**不会丢失**（自动保存）。
- 支持所有 16 种染色潜影盒及未染色版本。
- 目前仅支持 Minecraft 1.20.x 版本及 Spigot/Paper/Folia 核心。
